# Enhancing Cybersecurity Awareness: Investigating Phishing Preparedness Among UMN Students

This project is a formal research report completed for WRIT 3562W at the University of Minnesota. It investigates how prepared UMN students are when it comes to phishing attacks and proposes realistic strategies to improve cybersecurity awareness on campus.

## Key Features
- Surveyed 50+ students
- Interviewed UMN faculty and IT staff
- Incorporated data analysis + security principles
- Proposed feasible training strategies (e.g. Canvas modules, simulations)
